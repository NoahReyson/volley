Comment ajouter un exercice (document évolutif)

Tout est dans la liste EXERCICES en haut du script. Pour en ajouter un, copie un bloc existant et modifie les champs. Les filtres, les cartes et les schémas se mettent à jour automatiquement.

{
  nom: "Mon exercice",
  themes: ["Attaque", "Passe"],        // voir la liste des thèmes
  niveau: "Intermédiaire",             // Débutant | Intermédiaire | Confirmé
  joueurs: { min: 4, max: 8 },          // effectif mini / maxi
  duree: 15,                            // minutes
  materiel: "6 ballons, 2 plots",
  objectif: "Ce que l'exercice vise.",
  deroule: ["Étape 1", "Étape 2"],      // le déroulé, étape par étape
  consignes: ["Point clé 1"],           // points de coaching
  variantes: ["Plus dur : ...", "Plus facile : ..."],
  // schéma : terrain "full" (18m) ou "half" (9m), coords en mètres (x:0-9, y:0-18/9)
  schema: { terrain: "half", elements: [
    { type:"player", x:2, y:7, team:"A", label:"R" },
    { type:"ball",   x:2, y:1 },
    { type:"cone",   x:5, y:3 },
    { type:"arrow",  x:2, y:7, x2:5, y2:5, kind:"move" }, // kind: move | ball | pass
    { type:"zone",   x:6, y:0, w:3, h:3 },
    { type:"label",  x:7, y:6, label:"Cible" }
  ]}
}
